## Python Assignment - Exception Handling

This assignment is about learning exception handling in Python.

# Task 1: Safe Division
1. Used try-except for division.
2. Handled ValueError and ZeroDivisionError.
3. Used else and finally.

Functions/keywords used: 
- float(), try, except, else, finally

# Task 2: Bill Calculator
1. Created a bill_calculator() function.
2. Checked invalid and negative prices.
3. Used a loop to calculate the total bill.

Functions/keywords used: 
- bill_calculator(), isinstance(), raise, continue

# Task 3: Age Validator
1. Created a check_age() function.
2. Checked the age is between 1 and 120.
3. Used ValueError for invalid age.

Functions/keywords used: 
- check_age(), raise, try-except


# Task 4: File Reader
1. Took a filename from the user.
2. Read and displayed the first 3 lines.
3. Handled file-related errors.

Functions/keywords used: 
- open(), readlines(), FileNotFoundError, PermissionError, finally

# Task 5: Safe Shopping Cart
1. Created a shopping() function.
2. Added valid prices to a cart.
3. Handled invalid and negative prices.
4. Used q to exit the program.
5. Calculated total items and total bill.

Functions/keywords used: 
- shopping(), float(), append(), len(), sum(), raise
