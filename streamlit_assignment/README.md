# What I Learned
Through this assignment, I learned the basic concepts of Streamlit:

- How to create simple streamlit application by using st.title() and st.write()
- How to take user input using st.text_input(), st.number_input(), and st.selectbox()
- How to use button with st.button()
- How to use sidebar using st.sidebar()
- How to use condition statement with streamlit inputs
- How to display data using st.metric() and st.table()
- How to create charts using st.bar_chart()
- How to create a simple Sales Dashboard using Streamlit
